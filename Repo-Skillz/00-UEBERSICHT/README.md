# ACM API Connection Monitor — Lern-Repository

**Willkommen!** Dieses Lern-Repository führt dich Schritt für Schritt durch den gesamten Code des ACM API Connection Monitors – einer Echtzeit-Überwachungs-App für API-Endpunkte.

## Lernziele

- Verstehen einer **Full-Stack**-Anwendung (Rust + React + PostgreSQL)
- **REST-API**-Design mit Axum (Rust-Framework)
- **React 19** mit funktionalen Komponenten und Hooks
- **Asynchrones Monitoring** mit Tokio (Rust)
- **SQL**-Datenbank-Zugriff mit sqlx
- **Docker**-Multi-Container-Deployment
- **Spaceship-Cockpit**-UI-Design mit Tailwind CSS

## Wie nutzen?

1. **LERNPFAD.md** öffnen — empfohlene Reihenfolge
2. **ARCHITEKTUR.md** — großes Bild verstehen
3. **01-CORE-KONZEPTE/** — Grundlagen lernen
4. **02-DEPENDENCIES/** — jede Library verstehen
5. **03-CODE-ERKLÄRT/** — annotierten Code studieren
6. **04-CODE-ZUM-NACHBAUEN/** — selbst implementieren
7. **05-ÜBUNGEN/** — Wissen testen
8. **06-REFERENZ/** — immer griffbereit
